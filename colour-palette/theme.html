UI theme & treatment

Signature gradient
linear-gradient(90deg, #5E77FB, #7C6CF0, #22B8CF)
Thin 3px cap on cards, the hero KPI strip, and section dividers.
Cards
14px radius, 1px solid #DFE4FE border, soft blue-tinted shadow, gradient top cap, gentle hover lift.
Shadow / soft
0 1px 2px rgba(40,46,82,.05), 0 12px 28px -16px rgba(40,46,82,.14)
Shadow / lift
0 3px 10px rgba(40,46,82,.08), 0 28px 56px -22px rgba(94,119,251,.30) on hover.
Section accents
Each section header number cycles a cool hue for wayfinding: #5E77FB → #7C6CF0 → #2DB6C9 → #5B4BD1.
Type / display
Fraunces: headlines, big numbers, decks (italic for emphasis).
Type / body
Inter: all body copy and UI.
Type / labels
JetBrains Mono: eyebrows, tags, axis labels. Uppercase, letter-spacing .14–.16em.
Fonts hosting
Self-hosted, never a public CDN: millionpodcasts.com/research/assets/inter.css (ships Inter, Fraunces & JetBrains Mono together).
Chart logic
Emphasise the key bars in saturated colour; render the rest in the soft cool tints above. Keeps charts readable and clean rather than rainbow.
